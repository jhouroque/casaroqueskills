# Modelo de carta-proposta de emprego (Casa Roque, CLT)

Use como template-base do DOCX da carta-proposta. Substitua todo `[CAMPO ENTRE
COLCHETES]` pelo valor real ou deixe como espaço reservado para o JhEY preencher. Marque
claramente o que ainda falta antes de enviar.

> ⚠️ **Aviso:** Este modelo é uma **carta-proposta de emprego brasileira** (não "offer
> letter" americana). É um pré-contrato — a formalização é a **assinatura da CTPS
> (carteira) e o registro no eSocial**, feitos pela contabilidade. **Validar com a
> Contabilizei/advogado antes de usar:** piso da CCT de Limeira, exames admissionais,
> enquadramento. **Não há "emprego à vontade / at-will"** no Brasil — vale a CLT.
