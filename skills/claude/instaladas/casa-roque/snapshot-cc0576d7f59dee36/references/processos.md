# Processos Operacionais (POPs) — Casa Roque

## POP 1 — Emissão de NF e Etiquetas
- **Responsável**: Keila
- **Quando**: Diário, pela manhã
- **Meta**: 100% no prazo
- **Processo**:
  1. Acessar Bling → pedidos do dia anterior
  2. Emitir NF para cada pedido
  3. Imprimir etiqueta na Zebra
  4. Passar para Emerson separar
- **Prazos críticos**: Shopee até 11h | Site até 12h | ML variável

## POP 2 — Controle de Estoque
- **Responsável**: Emerson
- **Quando**: Diário + conferência Terça e Quarta
- **Meta**: Acurácia >95%
- **Processo**:
  1. Receber produtos do fornecedor → conferir contra pedido
  2. Registrar entrada no Bling
  3. Organizar por FIFO (mais antigo na frente)
  4. Separar pedidos enviados por Keila
  5. Reportar produto com <5 unidades para JhEY

## POP 3 — Batimento Semanal
- **Responsável**: Keila + Emerson
- **Quando**: Toda sexta-feira às 15h (fixo)
- **Meta**: Acurácia >98%
- **Processo**:
  1. Keila imprime relatório de NFs emitidas da semana
  2. Emerson confere contra estoque físico saído
  3. Qualquer divergência → reportar JhEY imediatamente
  4. Keila lança resultado no sistema

## POP 4 — SAC Marketplaces
- **Responsável**: Keila
- **Quando**: 3-4x por dia (manhã, meio-dia, tarde, tarde/noite)
- **Meta**: Resposta em <2 horas
- **Canais**: ML + Shopee + WhatsApp clientes (temporário JhEY 13-17h)
- **Processo**:
  1. Verificar mensagens e reclamações
  2. Responder dúvidas com respostas padrão
  3. Problemas complexos → escalar para JhEY via WhatsApp
  4. Reclamações de entrega → verificar rastreio + contatar transportadora

## POP 5 — Gestão de Tráfego e Ads
- **Responsável**: Thomas
- **Quando**: Diário
- **Meta**: ROI >3x | CPC <R$2,00
- **Ferramentas**: Google Ads (568-607-6835), Meta Ads, GA4
- **Entrega**: Relatório toda sexta para JhEY

## Fluxo de Compra de Estoque
1. Emerson identifica produto com estoque crítico (<5 un)
2. Informa Keila → Keila registra necessidade
3. JhEY aprova compra (obrigatório se >R$500)
4. Pedido ao fornecedor → entrada no Bling ao receber

## Procedimento de Devolução/Troca
1. Cliente aciona SAC (Keila)
2. Verificar prazo e condição do produto
3. Se aprovado: gerar etiqueta de retorno no marketplace
4. Produto retorna → Emerson verifica condição
5. Restock se íntegro / Descarte se danificado
6. Reembolso ou reenvio conforme caso
